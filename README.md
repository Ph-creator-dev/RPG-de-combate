# RPG de combate
Um RPG de combate feito em python utilizando os conceitos de POO.

# Conceitos de POO utilizados
- Polimorfismo
- Encapsulamento
- Herança

# Funcionalidades
- Atacar outro player

# Extras
- Aumento do dano dependendo do level
- Validação para o atributo vida
- Validação para o atributo level
- Validação contra ataque a si mesmo

# Utilização
Dentro do arquivo main.py, importe as classes usadas no arquivo RPG.py, crie dois ou mais objetos com nome, vida e level. Use o método atacar e passe o objeto alvo como parâmetro.
